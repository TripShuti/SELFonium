# Основні залежності

| Компонент | Призначення | Проєкт / ліцензія |
|---|---|---|
| AndroidX Media3 1.6.1 | Playback, sessions, HLS, data sources | [AndroidX Media](https://github.com/androidx/media), Apache-2.0 |
| AndroidX annotations | Позначення API | [AndroidX](https://android.googlesource.com/platform/frameworks/support/), Apache-2.0 |
| OkHttp 4.12.0 | HTTP | [OkHttp](https://github.com/square/okhttp), Apache-2.0 |
| desugar_jdk_libs 2.1.5 | Java API compatibility | [desugar_jdk_libs](https://github.com/google/desugar_jdk_libs), ліцензії та notices у проєкті |
| Gradle 8.11.1 | Build tool | [Gradle](https://github.com/gradle/gradle), Apache-2.0 |
| Android Gradle Plugin 8.9.2 | Android build integration | [Android tools](https://android.googlesource.com/platform/tools/base/), Apache-2.0 |

Цей перелік описує прямі залежності й інструменти; транзитивні компоненти мають власні ліцензії. Перед релізом перевір повний dependency graph і notices. MIT проєкту не замінює ліцензій залежностей. Ліцензії Android SDK приймаються окремо під час встановлення.
