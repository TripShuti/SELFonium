# SELFonium

Android-плеєр для локальної музики та власних медіасерверів. Без підписок і платного розблокування функцій.

**Android 8.0+ · Java 17 · Media3 · MIT**

Проєкт активно розвивається. Підключення, бібліотека й відтворення з Navidrome перевірені на пристрої; підтримка інших серверів потребує додаткового тестування.

## Можливості

- Музика з пристрою, імпорт аудіофайлів і прямі URL інтернет-радіо.
- Subsonic / OpenSubsonic, Jellyfin, Emby, Plex, WebDAV, Kodi та Audiobookshelf.
- Пошук, альбоми, виконавці, улюблене, історія й локальні плейлисти.
- Обкладинки Subsonic/Navidrome та вбудовані обкладинки локальних файлів із кешуванням.
- Фонове відтворення, системні медіакнопки, черга, перемішування, повтор, швидкість і таймер сну.
- Десятисмуговий EQ із Preamp, 18 пресетами, власними збереженнями та автозапасом рівня.
- Завантаження композицій для офлайн-прослуховування.
- Налаштування акцентного кольору, власний HEX-колір і чорний фон AMOLED.
- Темний графітовий інтерфейс, прямі вкладки бібліотеки, сітка 2/3 колонки та окремі сторінки альбомів і виконавців.
- Пошук з історією, черга з обкладинками й керуванням порядком, мініплеєр та адаптивний повноекранний плеєр.

Дані джерел шифруються через Android Keystore. Деталі підтримки серверів і поточні обмеження — у [документації](docs/FEATURES.md).

## Збірка

Потрібні JDK 17 або 21, Android SDK Platform 35, Build Tools 35.0.0, Bash, Python 3.11+, curl та unzip. Перший запуск завантажує Gradle і залежності.

У корені репозиторію:

```sh
bash scripts/build.sh
```

Якщо Android SDK ще не встановлено, Linux-скрипт встановить інструменти в локальну `.tooling`, запропонує переглянути ліцензії SDK та запустить збірку:

```sh
bash scripts/setup-android.sh
```

Наявний SDK визначається через `ANDROID_HOME` або `ANDROID_SDK_ROOT`; JDK можна вибрати через `JAVA_HOME`. Інші способи встановлення та перевірок описані в [BUILDING.md](docs/BUILDING.md).

Після успішної збірки:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Встановлення поверх попередньої debug-збірки з тим самим підписом:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Початок роботи

1. Відкрий **Налаштування → Джерела музики**.
2. Під’єднай сервер або додай файли з пристрою.
3. У **Бібліотеці → Композиції** натисни потрібний трек. Меню поруч із ним містить дії з чергою, плейлистами й завантаженнями.
4. Натисни мініплеєр для відкриття повного екрана відтворення.

Для Plex потрібні адреса самого сервера та його token. Для Kodi потрібно увімкнути HTTP/JSON-RPC доступ. WebDAV очікує адресу папки з музикою.

## Розробка

```sh
bash scripts/test-core.sh
python3 scripts/check-repository.py
```
