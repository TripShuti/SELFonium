# План розвитку

## Найближче

- Розширити тести playback, lifecycle, tap/overflow і великих бібліотек.
- Перевірити Jellyfin, Emby, Plex, WebDAV, Kodi та Audiobookshelf на реальних серверах.
- Покращити accessibility, локалізацію й адаптацію UI до екранів.
- Налаштувати стабільний release signing та випуск версій.

## Далі

- Import/export і редагування плейлистів, серверна синхронізація.
- Відновлювані завантаження, обмеження дискового кешу, робота без мережі.
- Обкладинки решти серверних адаптерів і тексти композицій.
- Android Auto та віджети.
- SMB, Cast/UPnP і додаткові джерела музики.

Пункти не є обіцянками строків. Для конкретної реалізації потрібні issue, перевірка сумісності й тести.
